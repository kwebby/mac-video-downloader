# Screenshot notes

These are real captures of MVD and its Chrome popup using an isolated demo library. Titles, transfer progress, counts, and browser connection data are test fixtures, so no personal download history is shown. The app screenshots use the production SwiftUI views. The Chrome screenshots use the production popup with a mocked desktop transport.

- `library-light.png`: download library in light mode.
- `library-dark.png`: the same library in dark mode.
- `chrome-light.png`: Chrome companion in light mode.
- `chrome-dark.png`: Chrome companion in dark mode.
